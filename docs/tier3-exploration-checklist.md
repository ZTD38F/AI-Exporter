# Tier 3 — 自由探索覆盖提醒（Checklist）

你已经完成了一轮自主探索。请**继续在当前子 Agent 会话和已有 Playground 中自由探索**，不要为了这一轮重新启动、重装或清空环境。下面是可能遗漏的产品功能地图，用来帮助你回顾已经实际体验过的内容，并决定下一步探索什么。

**这不是固定测试用例、点击脚本或必须完成的任务列表。** 不要求依次执行、逐项打勾或达到 100% 覆盖。优先尝试尚未探索的区域、不寻常的状态和功能之间的组合；如果发现可疑行为，允许继续深挖，不必为了清单跳过问题。只能基于真实的可见操作和结果描述覆盖情况；看到入口不等于成功验证功能。

## 1. 首次使用、导航与外观
- [ ] Popup、Options 工作台、Gemini 页面之间的入口、导航和返回
- [ ] 新手教程、引导气泡的定位/遮挡，以及首次触发的一次性弹窗
- [ ] 记录进入引导时实际显示的步骤；中途退出、重新打开、完成后的行为，避免把“看到部分步骤”算作完整引导通过
- [ ] 明暗模式切换、刷新后的外观、首屏闪烁、语言和不同视口下的可读性
- [ ] 按钮是否可发现、禁用状态是否合理、文案是否清晰、错误提示是否遮挡操作

## 2. 对话扫描与发现
- [ ] 首次扫描、重复扫描、增量扫描、没有新对话时的表现
- [ ] 新增、更新、置顶和较久以前的对话，分页加载与扫描后的列表变化
- [ ] 大量历史对话的进度与提醒（包括数量较大时扫描可能较慢）
- [ ] 扫描中、完成、空结果、失败、取消或重试时的 UI 与数据一致性

## 3. 对话列表与选择
- [ ] 单条选择、多选、全选、取消选择、筛选或搜索（如有可见入口）
- [ ] 标题、时间、排序、状态徽章和选中数量是否与用户看到的事实一致
- [ ] 扫描或导出后列表变化，当前选择是否仍符合用户预期
- [ ] 搜索无结果、清空搜索、切换筛选后的隐藏选中项；全选范围、选中计数与实际导出对象是否一致
- [ ] 未导出、已导出、有更新、部分附件过期等不同可达状态的显示

## 4. 手动导出与记录
- [ ] 单条、批量、大批量导出；大量选择时的一次性保存建议（如果触发）
- [ ] 已导出对话的再次导出、跳过已导出、更新后重新导出
- [ ] 任务执行中的进度、结果逐步更新、完成/失败反馈与可重试性
- [ ] 导出成功（含时间）、有更新、部分附件过期、导出失败、渲染成功等待下载等状态
- [ ] 导出历史与清理入口（如果可见），状态是否能对应实际文件与操作

## 5. 文件格式与实际内容
- [ ] Markdown、HTML、PDF、JSON 的选择、切换与导出
- [ ] 多轮/长对话、代码块、表格、数学公式、链接、引用及中英文混排
- [ ] 普通图片、生成图片、附件、失效资源等实际存在的富媒体
- [ ] 文件名、内容结构、内容完整性、可打开性和不同格式间的一致性
- [ ] 不只停留在“点击导出”；条件允许时，检查真实落地的文件和可见结果
- [ ] 下载文件路径来自本次 CLI 的结构化输出（`click --wait-download --json` 或 `wait-on --condition download_complete --json`），不要猜测系统 Downloads 路径；对支持的 Markdown / ZIP 使用 `evaluate-export --file <实际路径>`，分别记录“下载落盘”和“规范校验”的结果
- [ ] 同一对话切换格式后再次导出时，留意“跳过已导出”与导出记录的关系；HTML / PDF / JSON 若缺少可用的内容校验能力，应明确记录内容未验证，不能凭扩展名或文件大小判定完整

## 6. 浏览器下载与本地保存
- [ ] 浏览器直接下载、保存到本地文件夹这两种模式及其切换
- [ ] 选择文件夹、权限提示、目录状态变化、渲染完成但等待下载
- [ ] 取消文件夹选择或 Takeout 文件选择后，遮罩、忙碌状态和控件是否恢复，之后能否再次操作；若原生对话框不可被当前纯视觉接口观察或控制，记录限制，不推定取消成功
- [ ] 切换模式后相关设置、按钮启用状态和提示是否一致

## 7. 实时导出与实时保存
- [ ] 实时导出的启用/停用，以及新消息或对话更新后的可见反馈
- [ ] Markdown 与其他格式切换时实时导出的暂停或恢复行为
- [ ] 实时保存需要先选择本地文件夹；相关控件的依赖与禁用状态
- [ ] 切到浏览器下载时实时保存是否正确禁用；切回本地保存后的状态
- [ ] 连续更新、刷新页面、更改配置后是否出现重复、遗漏或状态错乱

## 8. Takeout 导入与数据合流
- [ ] Takeout 文件选择、导入进度、完成及失败反馈
- [ ] 导入后查看对话，尝试导出其中有代表性的内容
- [ ] 导入记录与在线扫描记录重叠时的去重/标题/内容显示
- [ ] 导入后再次扫描、更新、选择和导出的交互

## 9. 异常处理与恢复
- [ ] 无权限、资源不可用、附件过期、空内容或网络失败时的用户反馈
- [ ] 导出/扫描过程中切换设置、重复点击、取消、刷新或重试
- [ ] 运行中的进度条、文字提示是否互相矛盾或重复展示
- [ ] 一次失败之后其他对话、其他功能是否仍可继续使用
- [ ] 可见菜单和确认框的 Escape、Tab 焦点、取消及再次打开；覆盖无结果或失败状态下的键盘操作，观察焦点丢失和背景误触

## 10. 跨功能操作序列
- [ ] 扫描 → 选择 → 导出 → 对话更新 → 再扫描 → 再导出
- [ ] Takeout 导入 → 在线扫描 → 去重 → 导出
- [ ] 批量导出中修改导出格式、保存模式或选择状态
- [ ] 实时功能与手动导出、本地文件夹和页面刷新的组合
- [ ] 任何普通用户可能自然做出、但传统固定测试容易漏掉的操作顺序

## 11. 平台、账号与页面间的状态
- [ ] 可达的不同平台或账号之间切换时，列表、搜索、选中项、导出记录和操作目标是否对应当前来源；只有一个账号可用时，明确记为跨账号未验证
- [ ] Popup 与工作台之间切换格式、语言或保存设置后，另一页面的可见状态是否同步，是否影响当前选择和下一次导出
- [ ] 已连接、未连接来源和无来源页面的入口与提示；本地测试安装的 required 权限不能证明正式 optional 授权、拒绝或撤销流程通过
