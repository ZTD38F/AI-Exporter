# Gemini Exporter · 使用指南

[← 返回 README](../README_zh.md) · [English](./USER_GUIDE.md)

Gemini Exporter 将支持的 Google Gemini 对话保存到本地，**不提供云端托管备份或云同步服务**。

## 连接平台

在工作台打开**网站授权**，勾选需要的平台并点击**授权**。列表只显示尚未授权的平台；已授权的平台会隐藏。取消勾选不会撤销已有权限，撤销访问权需前往 Chrome 扩展设置。授权后，在来源网站登录，并在工作台选择对应账号。

![平台网站授权选择](../store_assets/screenshot_site_access_1280x800.png)

## 导出格式与保存方式

| 格式 | 适用场景 |
| --- | --- |
| **Markdown**（`.md`） | Obsidian、Logseq、笔记、可读的长期归档 |
| **HTML**（`.html`） | 浏览器离线阅读、公式排版和亮暗主题 |
| **PDF**（`.pdf`） | 阅读与分享；通过本地 Typst/WASM 编译 |
| **JSON**（`.json`） | 结构化数据备份与程序处理 |

可获取的图片与文件附件可能随 Markdown、HTML 或 JSON 一起保存到 `assets/`、`files/`。PDF 会按需嵌入图片，原始文件附件也可能作为独立文件输出。

工作台提供**浏览器下载**和**保存到本地文件夹**两种方式。浏览器下载涉及多个文件时自动打包 ZIP；本地文件夹模式直接写入各个文件。大批量导出通常更适合授权本地目录，避免浏览器下载时在内存中打包大 ZIP。

## 导出当前对话

1. 登录并打开 [Gemini](https://gemini.google.com) 中的一篇对话。
2. 在插件弹窗选择 **Markdown、PDF、HTML 或 JSON**。
3. 点击**导出当前对话**，通过浏览器下载保存。

## 批量备份

1. 在弹窗打开**工作台**，点击**同步会话**。
2. 搜索或筛选已扫描到的会话，勾选需要导出的条目。
3. 选择格式和输出位置；使用本地文件夹时需先选择目录并授权。
4. 点击**导出选中**。工作台会显示导出成功、有更新、失败或附件问题等状态。

**扫描不等于文件备份。** 同步只更新当前可访问会话的本地目录；**导出选中**才会创建备份文件。之后扫描不到的旧对话，不会仅因此从本地归档中删除。

**跳过已导出**仅跳过最近一次完整导出、格式一致且已知来源没有更新的会话。需要其他格式或来源已经改变时，请重新导出。

![展示实际同步 Gemini 对话的中文工作台](../store_assets/screenshot_3_1280x800.png)

## Markdown 实时保存

Gemini 回复完成后，可自动更新已授权目录中的 Markdown 文件。

1. 在工作台选择**保存到本地文件夹**，点击**选择文件夹**并授权。
2. 将格式设为 **Markdown (.md)**。
3. 在本地文件夹卡片内开启**实时保存**。

切换到**浏览器下载**或非 Markdown 格式时实时保存会**暂停**，开启偏好不会清除。浏览器重启导致目录权限失效时，需要重新授权。

## 通过 Google Takeout 补全历史

1. 从 [Google Takeout](https://takeout.google.com/settings/takeout/custom/gemini) 下载 Gemini 归档。
2. 在工作台选择归属账号，导入**原始 ZIP**（不需要手动解压）。
3. 选择导入的对话并正常执行导出。

Takeout 可以补充线上扫描无法获取的旧对话，但不能保证恢复已删除或已经过期的所有附件。

## 常见问题

**需要 API Key 或 Gemini 付费订阅吗？** 不需要。插件使用浏览器已有的 Gemini 登录会话；实际可读取的历史取决于账号及 Gemini 服务。

**ZIP 选项去哪里了？** ZIP 现在是浏览器多文件下载时的自动打包方式，并非独立导出格式；本地文件夹直接写入文件。

**实时保存可以输出 PDF/HTML 吗？** 暂不支持，实时保存仅支持 Markdown + 已授权本地文件夹。

**附件为什么没有保存？** 部分图片与文件链接可能失效。插件可提示检测到的资源问题，但无法还原 Gemini 不再提供的文件。

对于 `cdn.sanity.io` 图片下载失败，可展开**附件详情**，点击**允许从 cdn.sanity.io 下载**，确认可选网站授权后重新导出该会话。此授权与连接 ChatGPT 分开，可在 Chrome 扩展设置中撤销。

**PDF 导出一定要读取本机字体吗？** 不需要。本地 PDF 引擎可使用内置离线字体，PDF 仍完全在本机编译。

**能导出 ChatGPT、Claude 或 Grok 吗？** 源码版实验性支持 ChatGPT、Claude 和 Grok。在新手引导或“网站授权”中勾选需要的平台并授权，Chrome 仅申请所选平台会话与附件网站的访问权限。随后在对应网站登录，再选择账号、同步和导出。Grok 同步与导出时须保持已登录的 grok.com 标签页打开。无法获取的附件、暂不支持的工具或无法确定的分支可能导致部分导出。

**ChatGPT 问卷、交互卡片怎么导出？** 完整保留来源提供的 Markdown fallback，不因含有动态语法就把文字导出标为不完整。循环生成的表单还会从模板引用的字面量数组中补充题干和选项，不执行组件代码。动态组件没有可用 fallback 时，仍会标为不完整，因为仅提取字面量不能证明文字已全部恢复。按钮保存为文字，导出文件不还原交互状态、不提交问卷或执行 ChatGPT 操作；已选答案和计算结果只有在 fallback 或后续对话消息中存在时才会保留。

开发者可参考 [v2 模块架构](../src/README.md)和[测试指南](../tests/README.md)，数据处理细节见[隐私政策](./PRIVACY_POLICY.md)。

## 导入 OpenAI / ChatGPT 导出 ZIP

1. 连接 ChatGPT，在工作台选择对应的 ChatGPT 账户。导出包未提供工作区身份，需要自行选择正确的工作区账户；包内如有 `user.json`，用户身份必须与所选账户一致。
2. 打开 **更多操作 → 导入 OpenAI ZIP**，选择 OpenAI 官方数据导出的原始 ZIP；支持清单中声明的会话分片。
3. 选择导入的会话，按正常流程导出。导入器使用当前会话分支，保留可用的原始时间、模型、思考内容和引用，已有会话沿用正常的合流规则。

导出 ZIP 内的原始附件时，请保持工作台页面打开。关闭或刷新后，需重新导入 ZIP 以恢复附件读取。ZIP 字节不会写入会话领域数据。附件缺失会提示部分完成；文件库记录不会被伪造成会话。如果 `conversations.json` 是空数组，会明确提示导出包没有聊天正文。

**ChatGPT 返回 429 时怎么办？** 本次导出立即停止，账号冷却至少 1 小时；若 `Retry-After` 要求更久，则遵守更长时间。前台显示停止原因和冷却截止时间，到期后需手动重试。冷却按账号保存，刷新工作台或重启浏览器不会绕过。诊断保留限流和冷却记录。

停止或取消 Markdown、HTML、JSON 的浏览器导出时，已准备好的正文和已完成处理的会话附件仍会打包交付。正文 ZIP 与附件 ZIP 需解压到同一目录；尚未完成的附件不算成功，也不会生成完整成功记录。打包或交付失败会单独报告。PDF、Word 仍需完成渲染才能交付；文件夹模式已写入的文件会保留。

Markdown、HTML、JSON 的正文与附件分开交付：文件夹模式逐条先写正文，浏览器模式在正文准备完后先交付正文 ZIP，再交付附件 ZIP。PDF 和 Word 需要先准备附件再渲染。同一导出任务中，ChatGPT 正文与附件地址请求仍遵守相同账号冷却时间。

**原回答结束状态会影响导出成功吗？** 不会单独决定导出结果。明确结束、原回答中断、交接、最后为用户消息、停在工具步骤和结束状态未确认都是来源说明。正文覆盖完整且文件交付成功时显示“导出成功”；实际缺正文、缺附件或文件交付失败仍分别报告。隐藏节点的明确结束信号可用于判断结束状态，但隐藏内容不会因此进入导出文件。
